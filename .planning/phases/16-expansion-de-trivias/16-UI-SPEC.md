## Color

| Role | Value | Usage |
|------|-------|-------|

| Secondary | not applicable | Telegram handles surfaces |

**Color via Text Formatting:**
- Correct answer: `✨` prefix + `<b>` bold text
- Incorrect answer: `❌` prefix
- Protection: `🛡️` prefix
- Bonus: `🎁` prefix + special header text
- Streak: `🔥` prefix

**Accent reserved for:**
- Celebration messages (correct answer, tier reached)
- Protection offer keyboard
- Bonus question header

## Keyboard Layouts

### 1. Trivia Menu Keyboard (updated)

**Location:** `keyboards/inline_keyboards.py` — modify `game_menu_keyboard(is_vip, active_promo)`

```
┌─────────────────────────────────────┐
│ 🎲 Lanzar los dados del destino      │
│ ❓ Trivia Libre                      │
│ 🎫 Trivia con Promo (if promo active)│
│ 🔙 Volver                            │
└─────────────────────────────────────┘
```

**Visibility Rules:**
- `❓ Trivia Libre` — ALWAYS visible
- `🎫 Trivia con Promo` — ONLY visible when `active_promo` is truthy
- `🎲 Lanzar los dados del destino` — ALWAYS visible (existing)

### 2. Protection Offer Keyboard (new)

**Location:** `keyboards/inline_keyboards.py` — add `protection_offer_keyboard(cost, can_afford)`

```
┌─────────────────────────────────────┐
│ 🛡️ Proteger (-{cost} besitos)       │  <- only if can_afford
│ ❌ Continuar sin protección          │
└─────────────────────────────────────┘
```

**States:**
- If `balance >= cost`: Both buttons shown
- If `balance < cost`: Only "Continuar sin protección" shown

### 3. Free Bonus Keyboard (new)

**Location:** `keyboards/inline_keyboards.py` — add `trivia_free_bonus_keyboard(question, question_idx)`

**Layout:** Same as `trivia_keyboard()` but with special header text.

**Header for bonus questions:**
```
🎁 ═══ BONUS ═══ 🎁
+10 besitos por tu respuesta correcta
────────────────────────────
❓ Pregunta: {question}
```

### 4. Trivia Answer Feedback Messages

**Correct Answer (Free mode):**
```
✨ ¡Acertaste!

+{besitos} besitos agregado a tu cuenta.
🔥 Racha: {streak}

¿Continuar jugando?
```

**Correct Answer (Promo mode):**
```
✨ ¡Correcto! Llevas {streak} aciertos consecutivos.
```

**Incorrect Answer (Free mode):**
```
❌ Incorrecto.

Tu racha de {old_streak} se ha desvanecido.
No te preocupes: vuelve mañana para intentarlo.
```

**Incorrect Answer (Promo mode) — Protection Offer:**
```
❌ El silencio de una respuesta incorrecta es ensordecedor.

🛡️ ¿Deseas proteger tu racha de {streak}?

Costo: {cost} besitos

[Protection keyboard]
```

## Voice and Tone

**Lucien speaks in 3rd person:**
- "Lucien gestiona..."
- "El silencio de una respuesta incorrecta es ensordecedor."
- "Las preguntas están en el taller de Lucien."
- "Lucien hace una reverencia... medida."

**Never:**
- First person ("Yo" or "Yo controlo")
- Casual or vulgar language
- Direct commands to the user

**Elegant, mysterious, deferential to Diana:**
- "La fortuna es voluble"
- "El destino ha sido benevolent hacia usted"
- "El taller de Lucien espera su regreso"

### Callback Data Convention

| Callback | Format | Purpose |
|----------|--------|---------|
| Enter free trivia | `game_trivia_free` | Start free trivia session |
| Enter promo trivia | `game_trivia_promo` | Start promo trivia session |
| Free answer | `trivia_free_answer_{idx}_{qidx}` | Submit answer in free mode |
| Promo answer | `trivia_promo_answer_{idx}_{qidx}` | Submit answer in promo mode |
| Accept protection | `protection_accept` | User accepts protection |
| Decline protection | `protection_decline` | User declines protection |
| Free bonus continue | `trivia_free_next` | Continue after bonus answer |

### Daily Limits (from CONTEXT.md)

| Mode | Free User | VIP User |
|------|-----------|----------|
| Trivia Libre | 7/day | 15/day |
| Trivia Promo | 20/day | 30/day |

Limits are independent — playing free mode does NOT consume promo limit and vice versa.
