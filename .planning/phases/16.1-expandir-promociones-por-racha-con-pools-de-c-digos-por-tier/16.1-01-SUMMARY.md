# Phase 16.1 Plan 01 Summary: Tier-Based Code Pools

## Objective

Extender el sistema de promociones por racha de trivia para tener pools de codigos independientes por cada tier de descuento. Cada tier en discount_tiers JSON tiene su propio max_codes que controla combienos codigos pueden generarse para ese tier especificamente.

## One-liner

JWT auth with refresh rotation using jose library

## Decisions Made

1. **D-01**: JSON estructura: `[{streak: 5, discount: 50, max_codes: 10}, ...]`
2. **D-02**: Solo el tier mas alto alcanzado genera codigo (no stack)
3. **D-03**: Silent skip cuando pool agotado - retorna None
4. **D-04**: Pool depletion NO termina la promocion (otros tiers siguen disponibles)
5. Pool se agota cuando se ISSUE/GENERA el codigo (no cuando admin marca USED)
6. codes_claimed es para tracking de redenciones, NO para pool depletion
7. Pool depletion = codes_issued >= max_codes donde codes_issued se cuenta via query de DiscountCode
