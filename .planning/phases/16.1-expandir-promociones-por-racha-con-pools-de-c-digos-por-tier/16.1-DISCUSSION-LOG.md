# Discussion Log: Phase 16.1

**Date:** 2026-05-08

## Areas Discussed

### Area 1: Pool Structure (per-tier allocation)

**Question:** How should codes be distributed across streak tiers?
**Options presented:**
1. Total pool + tier percentages (Recommended) — max_codes global, cada tier define % del total
2. Per-tier max_codes — each tier gets its own limit
3. Shared infinite pool — todos comparten sin separación

**Selected:** Per-tier max_codes

---

**Question:** When a user hits a streak tier but that tier's pool is exhausted, what happens?
**Options presented:**
1. Hard boundary: tier pool must have availability (Recommended)
2. Automatic tier upgrade if pool depleted
3. Overflow queue with manual approval

**Selected:** Hard boundary: tier pool must have availability

---

**Question:** How should per-tier pool limits be stored in the database?
**Options presented:**
1. Extend discount_tiers JSON in place (Recommended)
2. Separate pool_limits JSON column
3. New PoolLimit model/table

**User response:** "En las cuestiones técnicas como en este caso tú tomas la mejor decisión para el sistema lo que sea más robusto y acorde a lo que ya está implementado"

**Decision:** Extend discount_tiers JSON in place + Claude discretion on implementation

---

**Question:** How should per-tier pool limits be stored and checked?
**Options presented:**
1. Extend discount_tiers JSON + tier pool check (Recommended)
2. Separate pool_limits JSON column
3. New TierPool model/table

**Selected:** Extend discount_tiers JSON + tier pool check

---

**Question:** When a tier pool is exhausted and a user reaches that streak, what message/behavior should they see?
**Options presented:**
1. Silent skip (no code, no message)
2. Notification on tier depletion
3. Early promotion end on depletion

**Selected:** Notification on tier depletion

---

**Question:** How should the depletion notification be delivered?
**Options presented:**
1. Just inform, let them continue (Recommended)
2. Inform and ask to continue or stop
3. Inform with protection offer

**Selected:** Just inform, let them continue

2. Todos los niveles completados

**Selected:** Solo el nivel más alto

**Question:** Which tier's pool availability is checked when selecting the code?
**Options presented:**

3. Check all completed tier pools

**Selected:** (user ended session — recommendations assumed)

### Area 3: Pool vs Individual Code Expiry

**Question:** Should pool depletion or promotion expiry control code validity?
**Options presented:**
1. Individual code expiry only (Recommended)
2. Pool expiry also invalidates unused codes
